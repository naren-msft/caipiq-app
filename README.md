# caipiq-app
Public information and getting-started page for the caipIQ internal desktop beta. Website assets only; app source and installers remain private.

The approved one-minute film, “Your account. Your edge.”, is public and uses only
illustrative motion and synthetic demonstration data. The website embeds the film
without offering video download links.

The second embedded film is a 75-second desktop walkthrough using actual
synthetic interface captures. It shows both chat and account view, plus reports,
background work, Frontier authoring and Connections. Both players retain
independent manual pause state and reduced-motion handling.

The page uses the smaller MP4 with native playback controls. Automatic playback
pauses offscreen and in hidden tabs, respects manual pauses, and is disabled for
reduced-motion preferences. A text alternative is available below the film.
